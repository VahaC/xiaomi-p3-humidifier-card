# Changelog

## 0.1.0

- First version: ring, compact and tank layouts, selectable in the card settings.
- Mode buttons (Off, Constant, Sleep, Strong) with optional scripts.
- Optional clean loop buttons with the minutes left.
- Target humidity slider and a draggable handle on the ring in Constant mode.
- Status chips for water, filter life, child lock and screen.
- Visual editor, English and Ukrainian.
